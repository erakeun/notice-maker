# 도트 캐릭터 65종

- 승인된 도트 하냥이 41종 / 도트 하이비비 24종을 사용합니다.
- `dot-characters.js`는 원본 포즈명, 순서, 아트보드 번호와 원본 파일명을 보존합니다.
- `dot-chars/`에는 검증된 SVG 65개와 투명 PNG 65개만 들어 있습니다. 원본 JSX, PDF, 대형 합본은 웹에 포함하지 않습니다.
- 썸네일은 스크롤 영역 근처에서 PNG를 불러오고, 선택한 캐릭터는 SVG로 표시합니다. 가로로 긴 문자 포즈도 원본 비율을 유지합니다.
- PDF / PNG / 인쇄 이미지는 선택한 SVG를 최종 300dpi 크기로 먼저 그려 확대 시 중간 저해상도 이미지가 끼어들지 않게 합니다. 투명 배경과 도트 경계를 유지합니다.

캐릭터 종류에서 도트 분류와 포즈를 고르면 아래 캐릭터 조절기가 선택됩니다. 기존 위치, 크기, 투명도, 회전, 좌우 반전, 앞뒤 순서와 잠금 기능을 그대로 사용할 수 있습니다. 문자·문양 포즈는 좌우 반전 안내를 확인해 주세요. `없음`을 선택하면 캐릭터가 제거됩니다.

작업파일은 기존 `charCategory`, `charIndex`, `objects.character` 필드를 사용하며 기존 일반 캐릭터 작업파일도 계속 읽을 수 있습니다. 자동저장은 같은 저장 키를 유지하며 탭 종료 시 대기 중인 변경을 저장합니다. 업로드 사진은 기존 정책대로 자동복원에 포함하지 않으므로 사진까지 보관하려면 작업파일을 저장하세요.
