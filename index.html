안내문 제작기

V1.7.0
OUTPUT SAFE · MOBILE EDIT

GitHub 루트의 chars / logos / templates 구조를 그대로 사용해. A4 인쇄용 안내문 전용 제작기. 웰컴보드는 별도 제작기로 분리했고, 템플릿 목록의 바로가기 카드에서 웰컴보드 제작기로 이동할 수 있어.

1. 용지 · 템플릿

2. 안내문 내용

부분 서식: 제목·부제목·본문·강조문·하단 문구 어디든 원하는 글자만 드래그한 뒤 B 또는 색상을 적용할 수 있어. 이탤릭·밑줄·부분 글자크기는 지원하지 않아.
글자색
미리보기의 제목·부제목·본문·강조문·하단 문구를 직접 드래그해서 위치를 옮길 수 있어.

3. 핵심 출력

PNG와 PDF는 화면 크기와 관계없이 A4 300dpi 상당 크기로 저장돼. 작업파일은 서버가 아니라 내 컴퓨터에 JSON으로 저장돼.
